# AB-Promo Website

A modern, responsive, and multilingual (Arabic, French, English) website for AB-Promo company.

## Features

- Responsive design using Bootstrap 5
- Multilingual support (Arabic, French, English)
- RTL/LTR layout support
- Modern and clean UI
- Animated sections and transitions
- Contact form
- Social media integration

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Bootstrap 5
- Font Awesome
- Google Fonts

## Project Structure

```
ab-promo-website/
├── css/
│   └── style.css
├── js/
│   └── main.js
├── translations/
│   └── translations.js
├── images/
│   ├── logo.png
│   └── hero.jpg
├── index.html
└── contact.html
```

## Setup

1. Clone the repository
2. Open `index.html` in your browser
3. The website should be fully functional

## Language Support

The website automatically detects the user's preferred language and switches between:
- Arabic (RTL)
- French (LTR)
- English (LTR)
